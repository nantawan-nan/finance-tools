# บรีฟ: ออกแบบหน้า "Cash Flow Forecast (มุมมองพนักงาน)" ใหม่

> เป้าหมาย: ทำให้ **สวยงามและใช้งานง่ายขึ้น** โดยเฉพาะตารางส่วนล่างที่ตอนนี้ดูยาก/แก้ยาก
> ส่งบรีฟนี้ให้ AI ดีไซน์ (เช่น Claude.ai) เพื่อขอ HTML + CSS ใหม่

---

## 1) หน้านี้มีไว้ทำอะไร

หน้า **"ประมาณการเงินสดรายวัน"** สำหรับพนักงานการเงิน ตอบคำถามเดียว:
> **"ถ้าจ่ายบิลที่ถึงกำหนดทั้งหมด เงินในบัญชีจะเหลือเท่าไหร่"**

แล้วพนักงาน **แคปภาพหน้าจอส่งรายงานเข้ากลุ่ม LINE ทุกวัน**

สูตรหลัก:
```
เงินคงเหลือต้นงวด + ประมาณการเงินรับ − ค่าใช้จ่ายถึงกำหนด = ประมาณการเงินคงเหลือ
```
ข้อมูลมาจาก (1) บิลเจ้าหนี้ (AP) ที่พนักงานกรอก "วันชำระเงิน" ไว้แล้ว + (2) ค่าใช้จ่ายประจำตามรอบ

---

## 2) โครงสร้างหน้า (บนลงล่าง)

1. **หัวเรื่อง** — ชื่อหน้า + ชิปบริษัท + ช่วงวันที่ + วันที่ยอดธนาคารล่าสุด + ปุ่มสลับ 📋 พนักงาน / 📊 ผู้บริหาร
2. **แถบกรองวันชำระเงิน** — ปุ่มลัด "ทั้งหมด" + รายวัน (สูงสุด 8 วัน) + เลือกช่วงวันที่เอง
3. **การ์ดสรุป 5 ใบ (KPI)** — เงินคงเหลือใช้ได้ / ค่าใช้จ่ายถึงกำหนด / ประมาณการเงินรับ / เงินคงเหลือสุทธิ / บัญชีติดลบ
4. **Cash Bridge** — แผนภาพสมการ (ต้นงวด + รับ − จ่าย = คงเหลือ)
5. **สถานะแต่ละธนาคาร** — การ์ดยอดเงินแยกบัญชี พร้อมโลโก้ธนาคาร
6. **ตารางค่าใช้จ่ายถึงกำหนดชำระ แยกตามหมวด** ⬅️ **จุดที่ดูยากที่สุด**
7. **แถบ "ค่าใช้จ่ายประจำที่ลบไว้"** (กดคืนค่าได้) + ปุ่ม Snapshot PNG / PDF

## 3) 🎯 จุดที่อยากให้แก้เป็นพิเศษ — ตารางหมวด (ส่วนล่าง)

### ปัญหาปัจจุบัน
- **อ่านยาก** — แต่ละแถวเป็นข้อความไทยยาว คั่นด้วย `—` และ `/` หลายชั้น
  เช่น `กรมสรรพากร — ภาษีซื้อ-ขาย /ภพ.30 — ภาษี` → ตาไล่ไม่ทันว่าอะไรคือ ชื่อเจ้าหนี้ / รายละเอียด / หมายเหตุ
- **แยกระดับหมวด vs รายการย่อยไม่ชัด** — แถวหัวหมวด (เช่น "ค่าใช้จ่ายประจำ") หน้าตาคล้ายรายการย่อยเกินไป
- **ปุ่มลบ (✕) เล็กและปนกับข้อความ** — กดยาก เผลอกดผิดได้
- **ตัวเลขจำนวนเงินไม่เด่น** — ทั้งที่เป็นข้อมูลที่คนอ่านอยากเห็นที่สุด
- **ไม่มีตัวช่วยจัดกลุ่มตามวัน** — เวลามีหลายวันปนกันดูยาก

### สิ่งที่อยากได้
- แยก **ชื่อเจ้าหนี้ / รายละเอียด / หมายเหตุ** เป็นคนละระดับ (เช่น ชื่อตัวหนา + บรรทัดรองสีจาง หรือใช้ chip หมวด) แทนการต่อด้วย `—`
- **หัวหมวดยุบ/ขยายได้ (collapse)** + โชว์ยอดรวมหมวดให้เด่น
- คอลัมน์ **วันครบกำหนด** กับ **จำนวนเงิน** อ่านง่าย — จัดกลุ่ม/คั่นตามวันได้ยิ่งดี
- **ปุ่มลบชัดเจน แยกจากเนื้อหา** (เช่น โผล่ตอน hover หรือไอคอนถังขยะท้ายแถว)
- รองรับรายการเยอะโดยไม่รก — zebra row / เส้นแบ่งเบา ๆ / sticky header
- เน้นให้ **อ่านชัดในภาพแคปหน้าจอบนมือถือ**

## 4) 🎨 แบรนด์ & ข้อจำกัด (สำคัญ — ต้องบอก AI)

- **ภาษาไทยเป็นหลัก** ฟอนต์ **IBM Plex Sans Thai** (ไทย) + IBM Plex Sans (อังกฤษ)
- 2 ธีมสีตามบริษัท: **M Bark = navy `#1e3a8a`** / Benya = teal `#0d9488`
- สีสื่อความหมาย: เงินเข้า `#14B8A6` (เขียว) · เงินออก `#E18AAA` (ชมพู) · ติดลบ/เตือน แดง · ระวัง เหลืองอำพัน
- โทนปัจจุบัน: **glassmorphism** (การ์ดโปร่ง มุมโค้ง เงานุ่ม `backdrop-filter: blur`)
- Icon: **Lucide** ผ่าน `<i data-lucide="ชื่อ">`
- ค่าติดลบแสดงเป็นวงเล็บ `(1,234.00)`
- ใช้งานจริง = แคปภาพอ่านบนมือถือ → ต้องอ่านชัดในภาพนิ่ง
- **เว็บไฟล์เดียว vanilla JS ไม่มี framework** → ขอผลลัพธ์เป็น **HTML + CSS ล้วน** (ห้าม React / ห้าม Tailwind build step)

## 5) โค้ดจริงของส่วนตาราง (ให้ AI ดูโครงสร้างข้อมูลจริง)

ส่วนนี้คือ Pivot table ที่ render อยู่ใน `renderToolCashflowStaff()` — ข้อมูลต่อ 1 รายการ (`p`) มี field:
`p.vendor` (ชื่อเจ้าหนี้) · `p.detail` (รายละเอียด) · `p.remark` + `p.internalNote` (หมายเหตุ) · `p.original_due` (วันครบกำหนด) · `p.amount` (จำนวนเงิน) · `p.type` (`"recurring"` = ค่าใช้จ่ายประจำ ลบได้) · `p.category` (หมวด)

```html
<!-- Pivot: ค่าใช้จ่ายถึงกำหนดชำระ แยกตามหมวด -->
<div class="card">
  <h3><i data-lucide="list-tree"></i>ค่าใช้จ่ายถึงกำหนดชำระ</h3>
  <div class="note">แยกตามหมวด · ${periodLabel}</div>

  <div class="table-wrap">
    <table>
      <thead><tr><th>หมวด / รายการ</th><th>ครบกำหนด</th><th class="num">จำนวน (บาท)</th></tr></thead>
      <tbody>
        <!-- แถวหัวหมวด (ซ้ำต่อหมวด) -->
        <tr class="cat-row">
          <td>ค่าใช้จ่ายประจำ</td><td></td><td class="num">295,572.26</td>
        </tr>
        <!-- แถวรายการย่อย (ซ้ำต่อรายการในหมวด) -->
        <!-- โครงสร้างคอลัมน์แรกปัจจุบัน:  vendor / detail — remark·internalNote  [ปุ่มลบ ✕] -->
        <tr class="sub-row">
          <td>กรมสรรพากร / ภาษีซื้อ-ขาย — ภพ.30 — ภาษี
            <button title="ลบออกจากประมาณการ (เฉพาะวันนี้)">✕</button>
          </td>
          <td>15 มิ.ย.</td>
          <td class="num">20,000.00</td>
        </tr>
        <!-- ... รายการอื่น ๆ ... -->
        <!-- แถวรวมท้ายสุด -->
        <tr class="tot-row">
          <td>รวมทั้งสิ้น</td><td></td><td class="num">514,235.66</td>
        </tr>
      </tbody>
    </table>
  </div>

  <!-- แถบค่าใช้จ่ายประจำที่ลบไว้ (กดคืนค่าได้) -->
  <div class="rec-skips">
    🗑️ ค่าใช้จ่ายประจำที่ลบไว้ (2):
    <span class="chip">TRUEMOVE H — ค่าโทรศัพท์ · 25 มิ.ย. <button>↩ คืนค่า</button></span>
  </div>

  <div class="btnrow">
    <button class="btn"><i data-lucide="image"></i>Snapshot PNG / PDF</button>
  </div>
</div>
```

**โครงสร้างที่อยากให้ AI ออกแบบใหม่** (ตัวอย่างไอเดีย — เปิดให้ AI เสนอได้):
- คอลัมน์แรกแตกเป็น 2 บรรทัด: **ชื่อเจ้าหนี้ (ตัวหนา)** / รายละเอียด+หมายเหตุ (สีจาง เล็กกว่า)
- หัวหมวดเป็นแถบยุบ/ขยายได้ + จำนวนรายการ + ยอดรวมหมวดเด่น ๆ
- ปุ่มลบเป็นไอคอนถังขยะ โผล่ตอน hover ที่ท้ายแถว
- จำนวนเงินใช้ตัวเลขใหญ่/หนาขึ้น ชิดขวา จัดคอลัมน์ให้ตรง

## 6) สิ่งที่ขอจาก AI ดีไซน์

1. ออกแบบ **ทั้งหน้า** ใหม่ให้ดูง่ายขึ้น โดยเน้นแก้ตารางหมวด (ข้อ 3)
2. ส่งเป็น **ไฟล์ HTML + CSS เดียว** เปิดในเบราว์เซอร์ดูได้เลย (mock data ไทยตามตัวอย่างด้านบน)
3. ทำ **2 ธีม** (M Bark navy / Benya teal) สลับด้วย attribute เช่น `body[data-co]`
4. คงโทน glassmorphism + Lucide icon + ฟอนต์ IBM Plex Sans Thai
5. ออกแบบให้ **สวยตอนแคปเป็นภาพ** (ไม่พึ่ง hover/interactivity ในการอ่านข้อมูลหลัก)
